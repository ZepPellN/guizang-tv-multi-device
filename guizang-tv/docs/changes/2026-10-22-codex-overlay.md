# Codex 首页输入浮层与胶囊消息

- Change-Id: `guizang-tv-20261022-codex-overlay`
- 执行者：Codex。
- 授权：用户要求参考 Libraries.dev Beam，将 Codex 改为首页底部输入框，带光效和由下向上的渐变模糊，自动打开输入法；消息取消角色标题，统一左对齐、独立胶囊显示。
- 基线：`881dac1d1b553882156180a9010f683fcd215098`。
- 来源：用户视觉要求、参考网站、现有 Android 实现和小米电视实机测试。没有使用参考网站的组件代码。

## 变化

- 原对话大面板改为当前 Activity 上的输入浮层。桌面在打开时截取清晰快照，后台计算两档高斯模糊并逐级遮罩，向下增强模糊与暗度。保留顶部清晰，不另加统一底板。快照也避免输入法调整后方 Activity 布局时出现桌面错位；打开期间背景与时钟快照静止，关闭后恢复实时桌面与原壁纸轮播。
- 深色圆角输入条下沿用原生 Canvas 绘制缓慢移动的彩色光效；柔光遮罩按尺寸缓存，不逐帧执行高斯模糊。退出或后台时停止刷新。
- 胶囊按内容决定宽度，长文换行，用户为深蓝色、回复为中性浅色；所有消息左对齐，不显示角色标签，无障碍描述保留发送方。滚动边缘渐隐，不使用头像或整体聊天底板。
- 进入已配对的浮层自动打开系统输入法；窗口随键盘调整，最新回复保持完整可见。键盘完成动作只收键盘并聚焦发送，发送仍须明确点击向上箭头。返回先关闭输入法，再关闭浮层。
- 新增 Phosphor Fill 的麦克风、向上箭头和停止图标，保留原 SVG、固定来源与 MIT 通知；VectorDrawable 使用相同路径数据。
- README、CODEX 与 AI-SETUP 同步新的入口、操作、验收与设备差异。可选本机语音命令仍为后台实验接口，当前浮层不再暴露其触发按钮。

## 保留

默认关闭及独立开关、已有配对、HTTPS 证书固定、请求鉴权、受限电脑服务均保留。没有扩展模型权限、接管小爱或 Home、改变遥控器配对；已有聊天和桌面偏好保留。无数据库迁移，无正式 Release。

## 验证

- 公开 Debug APK、既有 21 项 Java 测试通过；Android lint 为 0 errors / 22 warnings（含已有警告与自定义绘制、固定左对齐提示），私人同源 Release 构建通过。
- 小米 MiTV-MTSU0 / Android 14 / HyperOS 实机覆盖升级为私人 `3.4-codex-overlay-trial` / versionCode 15。
- 手动临时开启实验后验证：打开即显示搜狗输入法，输入条位于键盘之上；返回先收键盘，发送测试文字收到回答，输入框清空，消息和回复分别呈现为可见胶囊。
- 关闭再打开后自动显示输入法、定位最新消息；再次发送测试问题也收到并显示回答，顶部桌面与键盘展开前位置一致；修复初版键盘变化引起的最新消息裁切。真语音沿用此前用户确认的系统输入法回填路径，本轮没有替用户执行真实说话测试。
- 测试结束恢复原来的关闭状态，不清空配对或聊天，不停止用户电脑连接服务。
- 其他设备、其他输入法及公开签名新装尚未实测，不能以本机验证声称全部兼容。
