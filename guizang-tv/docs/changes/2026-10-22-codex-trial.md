## 变化

首页增加 Codex 入口，复用单色 Phosphor 填充图标体系。原生面板使用当前壁纸的模糊背景、圆角控件，支持连接设置、输入、流式回答、停止、新对话、遥控器浏览以及关闭回到原桌面。配对保存在应用私有偏好，无内置主机地址或凭证；面板关闭后停止轮询，已发起的回答在电脑继续完成。

新增 Python 局域网连接服务，用本机 stdio 接入已登录的 Codex。电视端固定校验证书指纹、有效期和 HTTPS 主机名，使用独立配对令牌。连接服务拒绝浏览器 Origin、无效鉴权、超长输入及任意 RPC 透传。试用只支持对话，关闭个人 MCP、插件、shell 和应用连接器，使用只读沙箱，不批准工具执行请求；没有接入用户文件、日程、米家或其他聊天记录。

提供可选本机语音命令适配接口，只把结果作为待确认草稿。国行实机没有标准 Android 语音识别服务；小爱日志确认遥控器语音链路正常。单独的私人实验适配器尝试短时读取本次小爱识别结果，没有改配对遥控器、改绑 Home / 语音键、停用小爱或录制音频。该私人适配器不纳入公开代码，不等同于通用麦克风驱动。首轮短时语音草稿测试超时，尚未验证成功。
