## 实现

阅读 BorderBeam 组件、line / pulse-inner / pulse-outside 样式生成器、Voice 底部光效及示例 CSS 中的明暗材质、backdrop-filter、内侧细描边和顶部高光。新增 `docs/BEAM-ANDROID.md` 记录固定源码链接、原生映射与取舍；保留上游 MIT 通知并随 APK 打包。使用公开源码，不引入运行时或 Pro 内容。

新增 `AssistantGlass`：在胶囊圆角内绘制按实际屏幕坐标对齐的浓模糊背景，降低其饱和度，再叠加明暗渐变底色、极弱静态颗粒和 0.75dp 内侧描边。顶部高光略亮、底边收敛。磨砂只作用于背景，文字不模糊。

用户为白色磨砂、深字；AI 为黑色磨砂、浅字。底部输入条复用黑色材质，保留独立彩色下沿亮边和柔光，去掉原实色底和重复描边。背景模糊共用缓存，不为每个胶囊重新计算；流式更新仅在角色变化时替换材质。滚动与键盘高度变化按当前位置取样。

保留默认关闭、已有配对、原文字输入/发送路径、渐变模糊、胶囊左对齐和无角色标签。没有配置迁移、账号权限变化或服务端改动；不创建正式 Release。
