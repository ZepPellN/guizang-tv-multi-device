## 发布范围

将此前 main 上的统一设置、视觉重做和宽幅 Dock 合并为正式 v0.3.0（versionCode 4）。包含背景 / 布局 / 字体 / 选中样式 / 首页内容 / 电视与启动六组设置；左侧选项、右侧圆角首页预览；候选壁纸与整页高斯模糊背景联动。按确定应用，返回取消尚未确认的壁纸预览。

首页支持文字、单色矢量图标或两者组合；列表焦点按内容宽度包裹。横向 Dock 使用宽幅圆角毛玻璃底板与大图标，六项居中，更多项目保持尺寸并随遥控器焦点平滑滚动。首页支持 1–9 项添加、隐藏和排序。原有固定 / 轮播偏好保留，默认每 5 分钟轮播。

README、设置指南、开机教程入口和兼容性说明随版本更新。v0.2.0 长篇项目介绍明确保留为历史指南，顶部链接新版操作说明。
