# 时间与天气（main 试用版）

此功能还没有进入正式 Release；v0.3.0 安装包不包含天气。当前 main 为 0.4.0-dev。

## 使用

进入「设置 → 时间与天气 → 显示天气」。默认关闭，开启后才自动联网获取天气。时间右侧显示单色天气图标、摄氏温度与城市；支持纵向列表和横向 Dock，设置预览同步显示实际已获取的数据。天气图标由矢量几何绘制，不使用彩色 Emoji 或远程图片。

自动城市由当前公网出口估算。代理、运营商出口和定位库偏差都可能导致城市不准；选择「手动选择城市」，输入中文名称或拼音，搜索后核对省份和国家再确认。搜索与返回不更改城市，只有选择结果才保存。城市搜索是用户主动发起的联网请求，即使天气显示关闭也可使用。

关闭天气会隐藏天气栏并停止自动请求，不影响时钟。切换城市会清除上一城市的天气，避免显示错配。照片、布局、首页顺序和启动偏好保留。

## 请求与缓存

- 首页可见时最多每 30 分钟刷新一次；离开首页、打开设置或其他应用时停止周期刷新。
- 在设置里明确开启天气或确认城市，会立即请求一次，以更新预览。已发出的请求允许完成；关闭天气或换城市后，旧响应不能再覆盖当前状态。
- 自动 IP 城市缓存最多 24 小时。尝试中文名称查询时，仅接受同一国家且距离 IP 坐标 35 公里内的匹配；失败则保留原城市名和原坐标，不阻断天气。
- 天气以服务返回的时间为准，最多显示 2 小时；过期、未来时间、无效温度和未知天气码不显示。网络失败不弹窗，短期保留有效缓存，在设置页提示状态；失败后同样等待刷新间隔。
- HTTPS 请求有连接/读取超时、响应大小限制；没有常驻后台服务。
- Open-Meteo 的当前天气来自数值天气模型，不应当作住宅门口传感器的实测值。

## 数据来源与许可

天气：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)，使用温度、WMO 天气码和昼夜标记。数据以 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 提供；显示时对温度取整，将天气码映射为中文描述和自绘图标。

城市搜索：[Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)，数据来自 GeoNames。自动 IP 城市：[IPWhois](https://ipwhois.io/documentation)。无需 API 密钥，没有把维护者账户凭据写进应用。

Open-Meteo 免费托管接口面向非商业使用，额度与商业接入规则见[官方定价](https://open-meteo.com/en/pricing)。项目代码的 MIT 许可不代表托管天气接口可无条件商用。接口可用性及国内网络连接需按实际环境验证。

## 隐私与权限

公开版新增 `INTERNET` 权限，不申请系统精确定位、GPS 或 Wi-Fi 扫描权限。服务提供者会收到请求的公网 IP；天气服务接收城市坐标，城市搜索服务接收搜索词。自动定位使用 IPWhois，不把系统精确位置上传。

应用只在本机保存所选城市、城市坐标、模式和天气缓存，不保存 IPWhois 的完整 IP 查询响应，不添加遥测或账号。关闭天气阻止后续自动查询，但不取消已经发出的网络请求。私人试用包保留历史 manifest 权限，不意味着天气功能使用了这些权限。
